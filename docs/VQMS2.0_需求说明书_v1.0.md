## 1 引言

### 1.1 目的

本文书定义 VQMS2.0 的功能与非功能需求，作为系统实现、测试验收、现场部署与后续演进的基准。系统核心使命：**按 2024 版"两个细则"对并网主体（本厂 2×350MW 火电）的 AVC 子站进行母线电压质量监测与考核记账，并为监管考核通知单提供对账能力。**

### 1.2 范围

- **考核侧**：附件 6 AVC 投运率/调节合格率两率考核（含免考三源判定）、正文第 26 条母线电压季度考核对账、第 27 条动态无功补偿装置考核对账
- **数据侧**：外部 AVC 历史库（qheatavchisdb，MySQL 5.7，无主键无索引 varchar 老库）的只读采集与数据质量治理
- **运营侧**：免考人工标注、退出原因标注、报表与 Excel 导出、参数与点号整定
- **不在范围**：第 27 条自动采集（信号无源，人工登记先行的对账能力）、有偿无功计量、月度结算返还（Phase 2，待外部口径确认）

### 1.3 术语

| 术语 | 定义 |
|---|---|
| AVC | 自动电压控制；主站闭环调节 → 子站执行 |
| 两率 | 投运率（合格线 99%）、调节合格率（合格线 100%） |
| 免考三源 | MANUAL（人工标注复核）> AUTO_YX（免考旗 yx）> AUTO_DEVICE（设备级 Q 极限判定） |
| 三状态 | 每档指令记账：QUALIFIED / PENALIZED / EXEMPTED / INVALID（无效=剔除分母） |
| 两档 | 调节快速性档 [1,t_fast] 分钟、调节经济性档 (t_fast,t_econ] 分钟，平行互不隶属 |
| τ 闸门 | 档窗口最低完整度（默认 50%），低于则判 INVALID 不硬判（数据公平性） |
| 4000+ 测试号段 | 测试开发阶段信号点号全部自定（4001-4020），现场接入按注册表整定换号 |

## 2 系统概述

### 2.1 背景与目标

电厂受东北能源监管局"两个细则"考核，AVC 电压质量直接挂钩罚款（1 分=1000 元）。VQMS 1.0 已完成核心算法验证；2.0 目标为**可现场部署的完整考核记账与对账系统**：判定逻辑纯函数化（可 TDD）、现场接线全面配置化（换号不改代码）、考核口径全面原子化（界面开关即改即生效）。

### 2.2 用户角色

| 角色 | 职责 | 系统入口 |
|---|---|---|
| 考核专工 | 看板/报表查阅、对账单导出、免考标注与复核 | 全部菜单 |
| 值守/运行 | 退出原因标注、月度数据登记（第 27 条） | 标注页 |
| 系统管理员 | 点号/参数整定、配置库导入、Quartz 任务管理 | 整定页 |
| 监管对账对象 | 接收对账单 Excel（离线） | — |

### 2.3 运行环境

- 应用：docker compose（backend:18080 / frontend:80 → nginx 反代 /prod-api）
- 数据：主库 ry-vue（考核记账）；外部源库 qheatavchisdb（只读，host.docker.internal 或容器网络）
- 定时：Quartz `vqmsStatsTask.recomputeYesterday()`，每日 03:00 缺口补算全链（单次上限 92 天）

## 3 功能需求

### 3.1 基础台账（配置数据）

| 需求 | 说明 |
|---|---|
| FR-1.1 并网主体 | 考核主体台账：类型、额定容量 kW（考核基数）、AVC 闭环标志、生效区间 |
| FR-1.2 母线组/主母线 | 220kV/500kV 按档登记；主母线号指示点、默认主母线、t0 实时电压点 |
| FR-1.3 无功设备 | 设备台账：类型（发电机/逆变器/SVC/电容/电抗）、静态 Q 额定、P/Q 遥测点、是否 AVC 闭环 |
| FR-1.4 P-Q 极限曲线 | 发电机类随 P 变化的双向 Q 极限（多点插值，带 effective_from 版本） |
| FR-1.5 母线电压阈值 | 合格区间（附件6：220kV±1kV、500kV±1.5kV），带生效区间 |

### 3.2 数据摄取与质量治理

| 需求 | 说明 |
|---|---|
| FR-2.1 指令摄取 | 外部 warn_info(type5) → vqms_command_ledger；亚秒就近取整到分钟；幂等 upsert |
| FR-2.2 目标值解码 | ROT10_V1：首位轮转码{1,2,3}+余值÷10；增量形态第 2 位循环码{0..5}校验（现场零实例，从严） |
| FR-2.3 0 值坏点拦截 | his_curve_sv high/low 任一 ≤0 视为坏点不采信（界面开关，默认拦截） |
| FR-2.4 完整度闸门 τ | completeness<τ 的档判 INVALID 不硬判（缺数窗不罚电厂；界面可整定 0=关闭） |
| FR-2.5 数据不可用处置 | A1 解码失败/A2 整窗缺/A2 L>H 异常行/A5 免考旗无源——各独立开关：0=剔除分母(默认)/1=计不合格 |
| FR-2.6 缺数≠离线 | 投运五信号整日全空 → 跳过不记账（防幻影 offline=1440 污染汇总） |
| FR-2.7 截断防护 | 源库查询达 maxRows(100 万) 上限即 ERROR 告警（静默截断会虚高合格率） |

### 3.3 调节合格率考核（附件6）

| 需求 | 说明 |
|---|---|
| FR-3.1 两档平行判定 | 快速性档 [1,t_fast]（t_fast 界面整定 1-4，默认 4）/ 经济性档 (t_fast,5]；包络判据 V_target∈[min(low),max(high)] |
| FR-3.2 三状态记账 | 每指令每档：QUALIFIED/PENALIZED/EXEMPTED/INVALID；参数快照随行（algorithm_id/t_fast_snapshot/decode_algorithm） |
| FR-3.3 免考三源 | 优先级 MANUAL> AUTO_YX > AUTO_DEVICE，逐档独立 |
| FR-3.3a MANUAL | 人工标注（warn_time_raw+millisecond+obj_num 溯源键）→ 复核（单账户自批/两级复核界面开关）→ APPROVED 重算生效 |
| FR-3.3b AUTO_YX | 免考旗 yx 阶跃保持采样：快档 @t0+tFast、经档 @t0+tEcon+1 |
| FR-3.3c AUTO_DEVICE | 附件6 §三：采样时刻曲线带偏离目标定方向（偏低→INJECT 顶发出上限/偏高→ABSORB 顶吸收下限），全部 AVC 闭环设备 Q 顶到各自极限（P-Q 曲线插值/容量圆/静态/单向）且容差内 → 该档免考 |
| FR-3.4 分档 VQMS 细化 | 不合格点按响应时长分档：[1,5)=快速性、≥5=经济性（外部依据待确认，阈值界面可整定） |
| FR-3.5 率/罚款重算 | DB 只落计数；率/缺额/罚款在查询层按 capacity 重算（快照随行防跨期口径漂移） |

### 3.4 投运率考核（附件6）

| 需求 | 说明 |
|---|---|
| FR-4.1 四桶分钟分类 | 逐分钟：投运/电网退出(免责出分母)/非电网退出(扣罚)/未并网 |
| FR-4.2 五信号语义键 | 并网编码主/副、AVC 投退、退出原因主/副——按 vqms_yc_point_map.point_key 消费 |
| FR-4.3 退出原因两级来源 | MANUAL 标注（vqms_exit_annotation 时段覆盖，GRID 免责/NON_GRID 扣罚）> AUTO_YC 遥测三态 |
| FR-4.4 日记账 | 逐日四桶分钟 + 率/缺额/罚款快照（幂等 upsert） |

### 3.5 第 26 条对账（母线电压季度考核）

| 需求 | 说明 |
|---|---|
| FR-5.1 季度曲线登记 | 调度下发的考核曲线（母线/季度/时段/上下限）CRUD + CSV 批量导入 |

### 3.6 第 27 条对账（动态无功补偿装置，风光储适用）

| 需求 | 说明 |
|---|---|

## 6 验收标准（摘要）

1. **判定正确性**：32 场景 manifest 验收 26/26（S 系列主指令全对，含免考源标记）；回放 harness 7/7 断言
2. **守恒**：分母 = 摄取数 = fast 合计 = econ 合计（逐批校验）
3. **口径原子化**：核实单全部口径项界面可整定，改后重算即生效，零代码变更
4. **现场可整定**：点号/容量/Q 额定经配置库整定落库；换号不改代码不发版
5. **可靠性**：并发重算被拒；半重算回滚；停机缺口自愈；操作全程留痕
